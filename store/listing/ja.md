# EyeTime — ストア掲載情報（日本語）

## Name
EyeTime — 集中・スクリーンタイム・目のケア

## Summary (≤ 132 characters)
集中セッション、気が散るサイトの手前の穏やかな一時停止、正直なスクリーンタイム統計、目のケア。無料・オープンソース・100%ローカル。

## Description
EyeTimeは、ブラウザと戦わずに深い作業へ入れるようにする拡張機能です。無料のオープンソースで、データはすべてお使いのデバイスに保存されます。

ワンクリックで集中
ツールバー、新しいタブ、Alt+Shift+F、コマンドパレット（Ctrl/Cmd+K）から、タイマー付きのセッションを始められます。モード（ディープワーク、スプリント、勉強）を選び、波に乗ったらあと5分を追加し、休憩はタイマーに任せましょう。気が散るサイトはセッションが終わるまで一時停止され、終われば自動で再び開けます。本気で取り組みたいときは厳格モードをどうぞ。

押しつけないブロック
カテゴリ（SNS、動画、掲示板、ニュース、ゲーム、ショッピング、メッセンジャー）を選ぶか、自分のサイトを追加します。完全に締め出すより、自分で決めた「もし〜なら、〜する」の計画を添えた短い深呼吸の一時停止のほうが効果的です。作業時間、サイトごとの1日の上限、1日の「気晴らし予算」も設定できます。

1日と1週間を計画
「今日の計画」は、優先タスクを実際に使える時間に収めます。「レポート 14:30 45m !」のように入力すれば、時刻・長さ・優先度をEyeTimeが読み取ります。カレンダーのリンクを購読する（またはファイルを読み込む）と、次の予定が集中カードに表示されます。週の目標は3つ、繰り返しタスク、MarkdownやCSVでのタスクの書き出し・読み込みにも対応しています。

正直な統計
サイト別・時間帯別・日別の時間。集中セッション付きの1日のタイムライン。プロジェクト（#タグ）別の集中時間。見積もりの精度（予定と実際）。最も集中できる時間帯。サイトに誘惑されるタイミングを示す「何に引き込まれるか」（ワンタップで上限も設定）。週のふりかえりと、共有できる「今週の画像」。どのサイトも、ワンタップで生産的・中立・気が散るに分類し直せます。CSVやMarkdownのジャーナルとして書き出せます。

穏やかな新しいタブ
時計、1日の目標つきの集中カード、優先度つきのタスク、習慣、メモ、クイックリンク。11種類のテーマ、好きなアクセントカラー、17種類の背景、本物の環境音。ライトとダークに対応。いつでもオフにできます。

目をいたわる
実際にアクティブだった画面時間に基づく20-20-20リマインダーと、20秒のガイド付き休憩ページ。

ショート動画ガード
ショート動画（YouTubeショート、Instagramリール、TikTok、VKクリップ）のスクロールが上限に達すると、ページがグレースケールになり一時停止します。

プライバシー重視の設計
アカウントなし。サーバーなし。分析なし。保存するのはドメイン名と秒数だけで、すべてお使いのデバイス上に保存されます。カレンダーのリンクを購読する場合、EyeTimeはそのファイル1つをブラウザから直接ダウンロードし、アドレスがデバイスの外に出ることはありません。任意の設定同期にはブラウザ自身の同期機能を使い、履歴は含まれません。コードはオープンソース（MIT）です：https://github.com/maxbzd/eyetime

対応言語：英語、ロシア語、スペイン語、ドイツ語、フランス語、ポルトガル語、イタリア語、ポーランド語、ウクライナ語、中国語、日本語。

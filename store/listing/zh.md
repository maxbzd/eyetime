# EyeTime — 应用商店介绍（简体中文）

## Name
EyeTime — 专注、屏幕时间与护眼

## Summary (≤ 132 字符)
专注时段、打开分心网站前的温和暂停、真实的屏幕时间统计与护眼提醒。免费、开源、100% 本地。

## Description
EyeTime 帮你专心做深度工作，而不必和浏览器较劲。它免费、开源，所有数据都只保存在你的设备上。

一键专注
从工具栏、新标签页、Alt+Shift+F 或命令面板（Ctrl/Cmd+K）开始一次限时专注。选一个模式——深度工作、冲刺、学习——进入状态时再加五分钟，休息计时交给 EyeTime。分心网站会暂停到专注结束，之后自动重新开放。真正需要时，还有严格模式。

尊重你的屏蔽
选择类别（社交、视频、论坛、新闻、游戏、购物、即时通讯），或添加你自己的网站。一段简短的呼吸暂停，加上你自己的“如果—那么”计划，比直接锁死更管用。还可设置工作时间、每个网站的每日上限，以及每天的“分心预算”。

规划一天和一周
“规划我的一天”会把你的优先任务排进你真正有空的时间。创建任务时输入“报告 14:30 45m !”这样的时间、时长和优先标记，EyeTime 就能读懂。订阅你的日历链接（或导入文件），即可在专注卡片上看到下一场会议。还有三个每周目标、重复任务，以及以 Markdown 或 CSV 导出和导入任务。

真实的统计
按网站、按小时、按天统计用时；带有专注时段的一日时间线；按项目（#标签）统计的专注时间；预估准确度（计划与实际）；你的最佳专注时段；“什么在拉走你”——某个网站何时诱惑你，并可一键设置上限；每周回顾，以及可分享的“我的一周”图片。一键把任何网站重新归类为高效、中性或分心。可导出 CSV 或 Markdown 日志。

宁静的新标签页
时钟、带每日目标的专注卡片、带优先级的任务、习惯、笔记和快捷链接。十一种风格、任意强调色、17 种背景、真实的环境音。支持浅色和深色。随时可以关闭。

呵护你的眼睛
基于真实活跃屏幕时间的 20-20-20 提醒，以及 20 秒的护眼休息引导页。

短视频守卫
刷 Shorts / Reels / TikTok / VK Clips 达到上限后，页面会变为灰度并暂停。

隐私优先
无需账号。没有服务器。没有统计分析。只保存域名和秒数——并且保存在你的设备上。如果你订阅日历链接，EyeTime 会直接从你的浏览器下载那一个文件；该地址绝不会离开你的设备。可选的设置同步使用浏览器自带的同步功能，不会包含你的历史记录。代码开源（MIT）：https://github.com/maxbzd/eyetime

支持语言：英语、俄语、西班牙语、德语、法语、葡萄牙语、意大利语、波兰语、乌克兰语、中文和日语。
